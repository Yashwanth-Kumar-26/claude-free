    Running in three commands.

    Setup is one cross-platform script for Linux, macOS and Windows. It needs Python 3.12.

    Clone and run setup

    git clone https://github.com/Yashwanth-Kumar-26/claude-free.git cd claude-free python setup.py

    Start the proxy

    claude-start-server

    Open Claude in your project

    claude

    What happens to a request.

    Claude Code never knows it left home. The gateway translates, streams, and hands back Anthropic-shaped events.

    1. FastAPI gatewayAuth, shortcuts and model selection.
    2. Backend adapterConverts the request format for the chosen provider.
    3. Transport layerHTTP streaming to the upstream.
    4. External APIThe provider endpoint you picked.
    5. SSE responseStreamed back to Claude in Anthropic format.

    Swap providers with one file.

    Edit config.json or re-run python setup.py. Providers are discovered from the models.dev catalog, so new ones need no code changes.

    { "provider": "open_router", "model_default": "...", "model_opus": "...", "model_sonnet": "...", "model_haiku": "..." }
